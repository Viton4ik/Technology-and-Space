# 🚀 Space Race: Orbital Spacecraft & Satellites (1957 – Oct 2026) | 3D Isometric Edition

Полностью автономный генератор 40-секундного вертикального 3D-видеоролика (**9:16, 1080x1920, 30 FPS**) в формате `.mp4` со звуковой дорожкой для **YouTube Shorts / Instagram Reels / TikTok**.

## ✨ Особенности 3D-версии «Технологии и Космос»:
1. **Настоящая 3D-изометрия полосок:** Каждая полоска отрисовывается как трехмерная призма с передней гранью, верхней изометрической гранью, боковым 3D-торцом, внутренним стеклянным бликом и глубокой падающей тенью.
2. **Космическая палитра Cyber-Cosmos:** Глубокий обсидианово-фиолетовый звездный фон (`#090614` / `#110b24`) с плазменным градиентом полосок (от аметистового и пурпурного до солнечного золота у лидеров).
3. **Новый телеметрический стиль и шрифты:** Моноширинные шрифты телеметрии (`DejaVu Sans Mono`), колонка рангов (`#01` – `#12`), верхняя капсула заголовка и нижний бортовой компьютер (HUD) с подсчетом общего числа аппаратов на орбите (`ORBIT TOTAL`).
4. **Полная автоматизация и самоочистка:** Скрипт сам создает виртуальную среду `.venv_space_race`, скачивает портативный `FFmpeg` и библиотеки, генерирует 40-секундный космический синтвейв-трек и удаляет за собой все временные файлы после сохранения `space_race_orbital_1957_2026_shorts.mp4`.

## 🚀 Как запустить:
Распакуйте архив и выполните в терминале (PowerShell):
```powershell
python run.py
```
